## The generator: audit

**How it was run.** Never against the repo's `data/`. First the file as found, unchanged, in a
scratch copy of the project (`tar` of the repo without `.git/` and `docs/`), into an emptied
`data/` there. Then, once changed, with the new `-- --out=<dir>` into a scratch folder. A
scratch-only script loaded every `.tres` on both sides (`CACHE_MODE_IGNORE`) and compared every
stored script property, and compared `balance.tres` with `BalanceData.new()`. `git status` showed
`data/` untouched after every run.

## export_presets.cfg

- `export_path` was `"../Release/Canadian Winter.exe"`, outside the repo. It's now
  `"build/windows/CanadianWinter.exe"`. `.gitignore` gets `/build/` under *Export outputs*.
  `*.exe` was already ignored; `/build/` also covers the `.pck`.
- **Secrets: none.** The file holds no key, password or certificate. `encrypt_pck` and
  `encrypt_directory` are false with empty filters, `codesign/enable=false` with no identity, and
  `ssh_remote_deploy/enabled=false` with Godot's placeholder host `user@host_ip` and its default
  scripts. Godot keeps keys in `.godot/export_credentials.cfg`, and `.gitignore` already ignores
  both `.godot/` and `export_credentials.cfg`.
- **An export works from the new path.** This was tried in the scratch copy: this PC's console
  build is non-mono and only the owner's `4.7.2.stable.mono` templates are installed, so the
  copy's preset pointed `custom_template/*` at them. The repo's preset wasn't changed.
  - With no `build/windows/`, `--export-release "Windows Desktop"` fails with "Prepare Template:
    The given export path doesn't exist." Godot doesn't create the folder.
  - With `build/windows/` made, it exits 0 and writes `CanadianWinter.exe` (109 MB, the mono
    template) and `CanadianWinter.pck` (43 MB).
  - The output was deleted afterwards.
- **For the owner (PR description):** before the first export, make the folder
  `build/windows` in the project (or make it in the export dialog's file browser). Otherwise
  Godot's export fails with "The given export path doesn't exist". The folder is ignored by git.
